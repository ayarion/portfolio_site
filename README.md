# Ayaka | Portfolio

水色のS字の道をハムスターと歩く静的ポートフォリオです。外部CDNやインストール、閲覧前のビルドは不要です。

## 閲覧

公開サイト、またはHTTPサーバーから開いてください。Node.jsがある場合は `node serve.cjs` で起動し、`http://localhost:8080/` を開きます。

最新の要件に合わせて画像・GLBのbase64埋め込みを廃止しました。ブラウザーの制限により `file://` ではGLBをfetchできないため簡易ハムスターになります。元のGLBを含む完全な表示にはHTTPが必要です。

## 操作

- トップは回し車のハムスターだけを表示。最低4秒後にクリック／タップ、またはEnterで街へ進みます。
- 縦スクロール、矢印キー、進みたい方向の長押しで歩きます。指・マウスを離すと止まります。
- スマホでは縦スクロールと右下の矢印の長押しが使えます。街へのタッチは220msの長押しで歩行に切り替え、それまでのスワイプはスクロールを優先します。
- 接近すると家へズームし、その後「入る」を表示。クリック、Enter、スペースで決定したときだけ開きます。Escapeまたは閉じるボタンで家の前に戻ります。
- 右上のメニューから4つの家を直接開けます。ダイアログ内でTab／Shift+Tabが循環します。
- チーム作品は詳細で外部遷移先を確認できます。作品リンクは最大1.05秒の回し車を表示して同じタブで移動します。Escapeで待機中の移動を取り消せます。
- OSの「動きを減らす」設定では自動スクロール・ズーム・歩行の揺れを省略し、外部リンクも即座に開きます。

## 後から差し替える箇所

`script.js` 冒頭の `window.PORTFOLIO` にまとめています。`TODO` コメントが目印です。

|内容|編集する項目|
|---|---|
|名前・自己紹介・SNS|`name` / `bio` / `github` / `x`|
|個人制作作品|`projects` 配列：togame、OjiMate、Kinto-Log|
|チーム制作作品|`teamProjects` 配列：mersampo。追加可能|
|作品の説明|各作品の `description`。現在は準備中のプレースホルダー|
|作品のリンク|各作品の `url`|
|スクリーンショット|各作品の `screenshots: [{src, alt}]`。先頭が代表画像|
|メールアドレス|`email`。空欄の間は「準備中」|
|スキル|`skills` 配列|

添付された10枚の画像を `assets/screenshots/` に収録しています。画像交換後は `src` と `alt` を更新してください。同じ名前で交換する場合はデータの変更不要です。トップの回し車には全画像を使用し、ギャラリー画像は遅延表示します。失敗時や `screenshots: []` の場合は作品名のカードに切り替わります。

## ファイル構成と配布

- `index.html`：導入、操作メニュー、ダイアログ、OGP
- `style.css`：配色、スマホ対応、表示アニメーション
- `script.js`：編集用データ、単一の進行度 `t`、画面遷移
- `world.js`：道、4軒の家、看板、カメラ、入力、ハムスターと回し車
- `vendor/three.bundle.js`：Three.js 0.169.0とGLTFLoaderの同梱版
- `assets/hamster.glb`：元のモデル。`hamster.glb.gz` はgzip版
- `assets/og-town.png`：実際の街を撮影した1200×630のOGP画像
- `assets/portfolio-type.js`：立体PORTFOLIOの同梱輪郭データ。フォントのライセンスも同じ場所に収録
- `assets/favicon.svg` / `favicon-32.png` / `apple-touch-icon.png`：アイコン
- `update-assets.cjs`：元のGLBからgzip版を更新
- `build.cjs`：gzip版を更新し、配布ファイルを `dist/` にコピー

`node build.cjs` を実行し、`dist/` の中身を静的ホスティングへ配置します。公開URLを変える場合は `index.html` のcanonical、OGP、Twitter画像URLも更新してください。家の順序と位置は `script.js` の `stops`、道の形は `world.js` の `PATH_POINTS` で調整します。

接近時のズームは `world.js` 冒頭の `APPROACH_ZOOM`（現在1.35）だけで調整できます。看板は各家より先のカメラ側の道端に配置し、正投影カメラの視線方向に文字面を向けています。0〜100%を1%刻みで、看板を家が遮らないことをPC・モバイル両サイズで検証しています。赤いシャツは元GLBの部品名を使って特定し、手がかりをコードコメントに残しています。

## 検証と制限

実GLBのgzip復元・読み込み、4秒の操作制限、長押しと停止、手足の歩行と待機、タッチとスクロールの切り替え、全4軒の接近・明示的決定・復帰、メニュー、画像の遅延読み込み、Escape、リサイズ、動きを減らす設定をプログラムで検証しました。

ブラウザーでは1280×860と375×812の表示領域で、導入から全4軒の開閉と終点への移動、描画継続を確認しています。モバイル確認はブラウザー内の指定サイズ表示で、物理端末による確認ではありません。WebGLが使えない環境では3Dを表示できませんが、メニューから内容を閲覧できます。GLB単体の読み込み失敗は簡易ハムスターへ切り替え、3D全体の失敗と分けて通知します。X側のカードキャッシュ更新は反映に時間がかかる場合があります。
