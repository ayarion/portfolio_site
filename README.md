# Ayaka | Portfolio

水色のS字の道をハムスターと歩く静的ポートフォリオです。外部CDNやインストール、閲覧前のビルドは不要です。

## 閲覧

公開サイト、またはHTTPサーバーから開いてください。Node.jsがある場合は `node serve.cjs` で起動し、`http://localhost:8080/` を開きます。

最新の要件に合わせて画像・GLBのbase64埋め込みを廃止しました。ブラウザーの制限により `file://` ではGLBをfetchできないため簡易ハムスターになります。元のGLBを含む完全な表示にはHTTPが必要です。

## 操作

- トップは回し車のハムスターだけを表示。最低4秒後にクリック／タップ、またはEnterで街へ進みます。
- 行きたい場所をタップ／クリックすると、その地点まで自動で歩き、到着すると待機します。道の外を選んでも、最寄りの道の中心線へ投影します。
- 途中で別の場所を選ぶと目的地が変わります。縦スクロールは画面全体で使え、スクロールを始めると自動歩行をキャンセルします。パネルの文章はコピーできます。
- 接近すると家へズームし、その後「入る」を表示。クリック、Enter、スペースで決定したときだけ開きます。Escapeまたは閉じるボタンで家の前に戻ります。
- 右上のメニューから4つの家を直接開けます。ダイアログ内でTab／Shift+Tabが循環します。
- チーム作品は詳細で外部遷移先を確認できます。作品リンクは最大1.05秒の回し車を表示して同じタブで移動します。Escapeで待機中の移動を取り消せます。
- OSの「動きを減らす」設定では自動スクロール・ズーム・歩行の揺れを省略し、外部リンクも即座に開きます。

## 後から差し替える箇所

`script.js` 冒頭の `window.PORTFOLIO` にまとめています。`TODO` コメントが目印です。

## ファイル構成と配布

- `index.html`：導入、操作メニュー、ダイアログ、OGP
- `style.css`：配色、スマホ対応、表示アニメーション
- `script.js`：編集用データ、単一の進行度 `t`、画面遷移
- `world.js`：道、4軒の家、看板、カメラ、入力、ハムスターと回し車
- `vendor/three.bundle.js`：Three.js 0.169.0とGLTFLoaderの同梱版
- `assets/hamster.glb`：元のモデル。`hamster.glb.gz` はgzip版
- `assets/og-town.png`：実際の街を撮影した1200×630のOGP画像
- `assets/portfolio-type.js`：立体PORTFOLIOの同梱輪郭データ。フォントのライセンスも同じ場所に収録
- `assets/favicon.svg` / `favicon-32.png` / `apple-touch-icon.png`：アイコン
- `update-assets.cjs`：元のGLBからgzip版を更新
- `build.cjs`：gzip版を更新し、配布ファイルを `dist/` にコピー

`node build.cjs` を実行し、`dist/` の中身を静的ホスティングへ配置します。公開URLを変える場合は `index.html` のcanonical、OGP、Twitter画像URLも更新してください。家の順序と位置は `script.js` の `stops`、道の形は `world.js` の `PATH_POINTS` で調整します。

接近ズームの基準は `world.js` 冒頭の `APPROACH_ZOOM`（1.35）。`CAMERA_PROFILES` でスマホ（480px以下）、タブレット（1024px未満）、PCを独立調整できます。`half` は横半幅、`ahead` は先を見る量、`house` は家への寄せ方、`approach` は接近倍率の補正、`offset` はカメラの向きです。スマホでは前方の道の左右範囲を中央へ合わせます。看板はカメラの向きに合わせて回頭し、0〜100%を1%刻みで家の遮蔽がないことを4サイズで検証しています。

タップはPointer Eventsのみで判定します。切り替え中の最初の入力は保持し、読み込み中は簡易ハムスターで操作できます。移動は経過秒数ベースです。速度は `script.js` の `tick` 内で調整します。15・30・60・120fpsで速度が一致することを検証しています。

## 検証と制限

実GLBのgzip復元・読み込み、4秒の操作制限、初回タップ、目的地への到着・変更、手足の歩行と待機、スクロールによる目的地のキャンセル、全4軒の接近・明示的決定・復帰、メニュー、画像の遅延読み込み、Escape、リサイズ、動きを減らす設定をプログラムで検証しました。

ブラウザーでは375×812、430×932、768×1024、1280×860で、開始画角、全4軒の開閉、スクロールによる終点への移動と描画継続を確認しています。モバイル確認はブラウザー内の指定サイズ表示で、物理端末による確認ではありません。WebGLが使えない環境では3Dを表示できませんが、メニューから内容を閲覧できます。GLB単体の読み込み失敗は簡易ハムスターへ切り替え、3D全体の失敗と分けて通知します。X側のカードキャッシュ更新は反映に時間がかかる場合があります。

## 建物と紙車

カメラは毎フレーム、0〜1に制限した進行度から道の位置を直接求めます。演出の補間は道からの相対オフセットだけに適用し、画面外へ出る場合は投影座標から補正します。4サイズで0〜100%を4回往復し、急なスクロールでもハムスターの頭と足が画面内にあることを検証しています。

`world.js` の `styleHamster` で元GLBを変更せず加工しています。HeadShape・ShortFurをクリーム色にし、Head配下に頬袋と白い下面を追加、Ear/InnerEarを縮小、Muzzle/Noseなどの奥行きを短縮しています。赤いシャツと既存の手足アニメーションは維持しています。

導入は4秒の最低表示時間を維持し、その時間を細い進捗バーで表示します。紙の厚み・反り、暖色と寒色の照明、半透明の床の落ち影、回転の緩急を加えています。「音をオン」で足音と息づかいを有効にできます。街には材質ごとの艶・粗さ、まとまりのある柵や花壇、風で揺れる木、流れる雲と鳥を追加しました。動きを減らす設定では環境アニメーションと音の演出を停止します。

自己紹介は「Introduce」の軒下ネームプレートとAyaka表札、多肉植物の店。個人制作は青い縞の日よけとショーウィンドウを備えた1階店舗。チーム制作は屋根窓・ポーチ・白い柵・動物のいる2階建て。お問い合わせはミント色の開放的な受付キオスクです。元画像のブランド名は使っていません。

紙車は時計回りに回転し、ハムスターは右向きに走ります。立体PORTFOLIOは右へ移動・拡大し、濃い青の側面でコントラストを付けました。375×812と1280×860で、スタートから進行度4%まで文字全体が画面内にあることを検証しています。
